## Versión aprobada de la promo

Secuencia continua de 90 segundos: apertura de 6 s; tres ejemplos de 15 s de pregunta y 6 s de festejo cada uno; invitación al stand; regreso a la portada. No es la versión antigua de una sola pregunta repetida seis veces.

1. Proteína por huevo: 6 gramos, respuesta A.
2. Peso promedio: 60 gramos, respuesta B.
3. Componente de la cáscara: calcio, respuesta C.

Títulos Fira Sans; textos Saira, por indicación del usuario de usar las fuentes de la trivia. Logo oficial de Feller. Textos con entrada y salida por palabras, tablet con perspectiva, respuestas escalonadas, «+1», pollitos, confeti y textura animada.

La respuesta correcta se muestra en rojo Feller **#ED3237 con texto blanco**, como en el artefacto del juego. Las demás opciones quedan al 45%. El amarillo de los primeros borradores fue reemplazado.

Los dos MP4 finales tienen 2700 cuadros. El exportador valida tres preguntas distintas, colores, fuentes, recursos y coincidencia exacta de primer y último PNG. El archivo comprimido puede introducir diferencias mínimas al decodificar.

## Fuentes y reproducción

- **Promo final:** `public/feller-led/vertical/{index.html,vertical.css,vertical.js}`.
- **Assets y licencias:** `public/feller-led/assets/`.
- **Exportador:** `tools/render-feller-vertical.cjs`.
- **Extracción de SVG originales:** `tools/extract-feller-art.cjs`.
- **Borrador horizontal anterior:** `public/feller-led/index.html`, `promo.css`, `promo.js`. Se conserva como referencia; no es la entrega final.
- **Detalle técnico de la promo:** [README vertical](../../public/feller-led/vertical/README.md).

```sh
npm ci
npx playwright install chromium
npm run feller:export:check
npm run feller:export
npm run feller:export:high
```

FFmpeg debe estar instalado y disponible en PATH. Se usa Chromium de sistema si existe, `CHROMIUM_PATH` si se indicó, o el de Playwright. La promo no necesita Supabase ni variables privadas.

Para la vista web: `npm run dev` y abrir `/feller-led/vertical/index.html`. Para una carpeta de salida distinta: `node tools/render-feller-vertical.cjs --high /ruta/salida`.

Los MP4, PNG y ZIP de trabajo quedan en `exports/`, excluido de Git. Los finales están en Drive; el código, las fuentes, las licencias, las vistas de referencia y el manifiesto están en Git.
